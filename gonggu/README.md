# 아리랑 공구팜 (PWA)

아리랑식품영농조합법인 제품만 판매하는 공동구매 웹앱입니다. 서버·빌드 없이 정적 파일만으로 동작하며 Cloudflare Pages 무료 플랜에 올릴 수 있습니다.

## 구조

| 파일 | 역할 |
|---|---|
| `js/config.js` | **운영자가 수정하는 유일한 파일** (상품·가격·마감일·구매링크·회사정보) |
| `js/app.js` / `css/styles.css` / `index.html` | 앱 본체 |
| `manifest.webmanifest`, `sw.js`, `icons/` | 홈 화면 설치(PWA) |
| `_headers` | Cloudflare 보안 헤더 |
| `docs/google-apps-script.gs` | (선택) 익명 통계를 Google Sheets에 저장 |

## 오픈 전 체크리스트

1. 카페24에서 공구 전용 상품을 등록하고 각 상품 주소를 `config.js`의 `url`에 입력
2. `regular`(정상가)는 **실제 판매해 온 가격**만, `price`는 공구가로 수정
3. `endAt`(마감일시)을 실제 일정으로 수정 — 마감이 지나면 자동으로 "마감" 표시
4. `company`(대표자·사업자번호·통신판매업 신고번호·고객센터)와 `policy`(배송·환불) 입력
5. `links.privacy`에 쇼핑몰 개인정보처리방침 주소 입력
6. `draft: false`로 변경 (상단 "시안" 띠가 사라짐)
7. 상품 사진을 쓰려면 `icons/`와 같은 방식으로 이미지를 올리고 app.js의 deal-visual 부분을 교체

> 신제품(청비환·배도라지환·관절환)은 품목제조·표시사항 확인 전까지 `upcoming`(관심 표시만)에 두세요. 효능·효과를 암시하는 문구는 넣지 마세요.

## Cloudflare Pages 무료 배포

1. GitHub에 이 폴더를 저장소로 올립니다.
2. Cloudflare 대시보드 → Workers & Pages → Create → Pages → Connect to Git
3. 빌드 명령 비움, 출력 디렉터리 `/` 로 배포
4. 발급된 `https://○○○.pages.dev` 주소를 카카오톡·문자·SNS로 공유

(저장소 없이 `config.js`만 고쳐서 다시 올리는 "직접 업로드" 방식도 가능합니다.)

## 통계 수집 켜기 (선택, 무료)

`docs/google-apps-script.gs` 상단 안내대로 배포한 웹앱 URL을 `config.js`의 `analytics.endpoint`에 넣으면 조회·공유·구매클릭·관심 수가 Google Sheets에 쌓입니다. 개인정보는 수집하지 않습니다. 쌓인 데이터는 공구별 전환율, 어떤 상품이 공유를 많이 받는지 분석하고 신제품 기획에 활용할 수 있습니다.

## 운영자 도구

주소 뒤에 `?admin=1` 을 붙이면 "운영" 탭이 나타납니다. 공구 손익 계산기, 월 매출 목표 역산, 이 기기의 이용 기록(CSV)이 있습니다. 비밀 정보는 없으므로 공개되어도 안전합니다.

## 의도적으로 넣지 않은 것 (신뢰 보호)

- 가짜 참여자 수, 가짜 카운트다운, 부풀린 기준가 — 마감시각은 `endAt` 실시간 기준
- 구매 확인 없이 지급하는 추천 보상 — 공유 링크는 통계용이며 혜택을 확정하지 않음
- 앱 안의 개인정보·카드정보 수집 — 결제는 카페24에서만
